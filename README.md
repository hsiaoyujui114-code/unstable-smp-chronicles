# 🎮 Unstable SMP 宇宙編年史與主角全紀錄
### The Ultimate Unstable SMP Interactive Lore & Character Vault

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-brightgreen?style=for-the-badge&logo=github)](https://hsiaoyujui114-code.github.io/unstable-smp-chronicles/)
[![Architecture](https://img.shields.io/badge/Architecture-100%25%20Static%20HTML5-blue?style=for-the-badge)](https://github.com/hsiaoyujui114-code/unstable-smp-chronicles)
[![License](https://img.shields.io/badge/License-MIT-orange?style=for-the-badge)](LICENSE)

專為 **Minecraft: Unstable SMP（Unstable Universe）** 打造的沉浸式劇情解說、主角全視角編年史、意外漏洞神裝展示庫，以及內建互動決策冒險遊戲！

本專案採用 **100% 純靜態 HTML5 + CSS3 + 原生 JavaScript (ES6)** 架構，**完全不需要 Node.js、Python 或任何後端伺服器**，本地雙擊即可直接執行，並可直接推送部署至 **GitHub Pages**！

## 🌟 核心特色 (Key Features)

### 1. 👑 四大傳奇主角個人全專區 (The Four Protagonists)
深度拆解並整合四位核心靈魂人物的完整生平與人格演化：
* **Parrot (ParrotX2)**：
  * **稱號**：伺服器調查者 · 越獄智將 · 第一任民選國王
  * **主線故事**：從意外挖出「毀滅世界按鈕」、在絕海黑牢 Paragon 監獄中以紅石偷運物資大越獄、加冕登基為王經歷凶險治理風暴，到統帥千人大內戰。
  * **意外神器**：`Parrot's Spyglass`（靈魂觀測望遠鏡）、`World Destroyer Button`（世界毀滅按鈕）、`Smuggled Paragon Shulker`（走私黑牢潛影盒）、`The Sovereign Scepter`（國王權杖）、`Null Code Compass`（虛空代碼羅盤）。
* **Wemmbu**：
  * **稱號**：力量泰坦 · 禁忌金庫掠奪者 · 帝國文明統治者
  * **主線故事**：隻身強攻全服防守最森嚴的非法基岩金庫奪取神物、在數十名獵人圍攻下化身「不可捕捉者」、建立繁盛文明摧毀 PrinceZam 帝國、為洗滌腐敗親手毀滅伺服器，以及為了摯友 Eggchan 血洗黑手黨。
  * **意外神器**：`The Crucible & Gambit`（天罰破甲裁決巨刃）、`Eggchan’s Keepsake Book`（摯友血盟筆記）、`Sky Grav-Core`（浮空島反重力神核）、`Banned Vault God-Axe`（禁斷碎盾神斧）、`Orbital Cannon Remote`（軌道加農砲控制器）。
* **Spoke (SpokeIsHere)**：
  * **稱號**：漏洞神偷 · 陷阱詭術大師 · 黑手黨致命雙面臥底
  * **主線故事**：在系列揭幕之際即以水流漏斗卡死伺服器的古老漏洞向全服宣戰、挖掘旁路管道神不知鬼不覺搬空 10,356,000 件複製神裝、搞垮全服首富經濟體、臥底黑手黨高層並在首腦峰會引爆共振礦車終結犯罪家族。
  * **意外神器**：`10,356,000 Duped Gear Hoard`（千萬級複製物資秘藏）、`The Totem of Null`（穿牆不死圖騰）、`Dean’s Screaming Goat Horn`（哀號悲鳴山羊角）、`Mafia Black Ledger`（黑手黨賄賂密碼本）、`Resonance Minecart Detonator`（共振秒殺瞬爆礦車）。

  * **稱號**：不死戰神 · 極限生存先鋒 · 萬軍角鬥之王
  * **主線故事**：在硬核極限環境下利用生命同步毫秒差卡出令全服震驚的「常駐不死金心」、孤狼 1v5 剿滅毒瘤公會並在廢墟中拾獲純真之花、拜師死神 ClownPierce 經歷地獄修煉繼承收割戰鐮，並在萬人大內戰中身扛先鋒軍旗鑿穿敵陣。

### 2. 🎬 核心劇集影音放映廳 (Video Theater & Detailed Breakdowns)
* 收錄四大主角全部關鍵劇集與影片檔案。
* 內建 16:9 劇院模式彈窗播放器，可直接線上觀看 YouTube 嵌入或一鍵跳轉官方頻道。
* 每一集皆附帶：
  * 發布日期與片長
  * 劇情核心脈絡與轉折點剖析
  * 該集所獲得之「意外禁忌物資 / 關鍵戰利品」標籤

---

### 3. 📜 四視角同步事件矩陣 (Multi-POV Timeline Matrix)
* 打破傳統單一時間軸限制，採用**多維度事件矩陣**：
  * 第一紀元：代碼裂縫與伺服器初啼
  * 第二紀元：大追捕與 Paragon 絕海黑牢大越獄
  * 第三紀元：文明崛起、帝國爭雄與經濟崩盤
  * 第四紀元：暗夜風暴！黑手黨崛起與無間滲透
  * 第五紀元：王權興衰與萬人大內戰（終局之戰）
* 在同一個歷史事件點，橫向一覽 Parrot、Wemmbu、Spoke、FlameFrags 四人當時各自在經歷什麼冒險。

---

### 4. 🎮 內建互動解謎冒險小遊戲 (Unstable Survival Quest)
滿足將「遊戲互動打包至靜態頁面」的體驗：
* **純前端文字 RPG 引擎**（位於 `js/game.js`）。
* 玩家可自由選擇 4 位主角之一開局。
* 進入經典劇情分支抉擇（如是否按下毀滅按鈕、如何突破基岩金庫、如何臥底黑手黨、如何卡出不死金心）。
* 內建主角背包與神器檢定系統。
* 包含多重結局（傳奇國王、自由先驅、鐵血霸王、終結者、幕後大玩家、虛空幽靈、不朽戰神等）。
* 支援進度自動儲存（LocalStorage）與重置。

---

### 5. ⚡ Web Audio API 音效合成引擎
* 零外部音效檔案依賴，使用原生 Web Audio 震盪器即時合成：
  * Minecraft 經典介面按鈕點擊音效
  * 拾取經驗球經典升級雙重叮聲 (Level-Up Ding)
  * 伺服器異常代碼共振低頻嗡鳴 (Glitch Hum)

---

### 6. 🔍 快速檢索搜尋器 (Command Search)
* 支援鍵盤快速鍵 `Ctrl + K` 或 `Cmd + K` 開啟全域檢索。
* 即時模糊搜尋所有主角、影片標題、意外物品與劇情關鍵字，並支援一鍵平滑跳轉。

## 🚀 部署與本機運行指引 (Deployment & Local Usage)

### 本地直接執行 (Local Preview)
因為本專案為純靜態頁面，**不需要任何本機伺服器**：
1. 下載或複製本儲存庫到電腦上。
2. 直接雙擊 `index.html`，即可在任何瀏覽器（Chrome, Edge, Safari, Firefox）中流暢運行！

### GitHub Pages 線上發布 (GitHub Pages Setup)
本專案已完全相容 GitHub Pages：
1. 將代碼推送至 GitHub 儲存庫的 `main` 分支。
2. 進入 GitHub 專案頁面 -> **Settings** -> **Pages**。
3. 在 **Build and deployment** 下方的 **Source** 選擇 `Deploy from a branch`。
4. Branch 選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
5. 數分鐘後即可透過專屬網址造訪：
   ```text
   https://<你的GitHub使用者名稱>.github.io/unstable-smp-chronicles/
   ```
